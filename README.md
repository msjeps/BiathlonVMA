# BiathlonVMA
Biathlon VMA est une application éducative conçue pour les cours d'EPS en collège/lycée, permettant aux élèves de suivre la régularité de leurs courses ainsi que leurs performances lors de séances de biathlon, combinant courses et tirs de vortex (lancers longs).

# 📦 Contenu du package

- `index.html` - Application principale (votre version actuelle)
- `manifest.webmanifest` - Configuration PWA
- `service-worker.js` - Cache offline
- `icon-192x192.png` - Icône application (petite)
- `icon-512x512.png` - Icône application (grande)

# 🚀 Installation rapide

1. **Téléchargez tous les fichiers** dans le même dossier
2. **Ouvrez `index.html`** dans un navigateur
3. C'est tout ! L'application fonctionne **100% offline**

# 📱 Installation sur tablette

## Android 
1. Transférez tous les fichiers via USB
2. Ouvrez `index.html` avec Chrome
3. Menu → "Ajouter à l'écran d'accueil"

## iPad
1. Transférez via AirDrop ou iCloud
2. Ouvrez `index.html` avec Safari
3. Partager → "Sur l'écran d'accueil"
